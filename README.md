# StockSense — AI Inventory for Nowshera Shopping Mall

GitHub-ready Next.js + Supabase inventory project.

## Setup
1. Run `supabase/schema.sql` in Supabase SQL Editor.
2. Copy `.env.example` to `.env.local` and add Supabase keys.
3. Run `npm install`
4. Run `npm run dev`

## Included
- Products and stock movements
- Supabase RLS
- Stock In / Stock Out RPCs
- Zero-stock protection
- Staff-safe inventory view
- AI API fallback endpoint
- Next.js dashboard
